# Retired merge-patch evaluation tools

These files belong to an earlier evaluation of JSON Merge Patch implementations. They target a removed `jsontailor.merge_patch(jsonb,jsonb)` API and are retained only as historical research material.

They are not part of the supported `pg_jsontailor` duality-view product, are not executed by current CI, and must not be used to verify a current installation. The supported extension contract is checked by `tests/verify_installation.sql`.
