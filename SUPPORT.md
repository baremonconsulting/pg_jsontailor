# Support

Community support is provided on a best-effort basis through GitHub issues for
reproducible bugs and focused feature requests. No response time, warranty or
service-level commitment is implied. Include the extension version, PostgreSQL
version, a minimal synthetic schema and specification, the SQLSTATE and exact
reproduction steps.

Do not publish credentials, personal data, customer identifiers or production traces. Report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/baremonconsulting/pg_jsontailor/security/advisories/new), as described in [`SECURITY.md`](SECURITY.md).

Commercial migration, architecture and implementation support may be agreed
separately with [Baremon s.r.o.](https://www.baremon.eu/). Repository text is
not such an agreement.

For a controlled pilot, use only the private support channel named in the
written [Pilot scope record](docs/PILOT_READINESS.md#2-pilot-scope-record).
Do not place customer schemas, samples or diagnostics in a public GitHub issue.
